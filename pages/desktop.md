## 📋 Описание

OnSiteSeq Desktop — вариант системы управления биоинформатическими пайплайнами OnSiteSeq Cockpit, адаптированный для работы на рабочем компьютере исследователя или лаборатории. Может работать в паре с OnSiteSeq Edge или использовать данные, полученные на другом оборудовании.

---

## 🔧 Ключевые характеристики

| Параметр | Значение |
| :--- | :--- |
| **Архитектура** | x86 |
| **Целевое устройство** | Рабочий компьютер |
| **Реестр контейнеров** | harbor.onsiteseq.io (x86 Docker-образы) |

---

## ⚙️ Возможности

* Управление пайплайнами через веб-интерфейс Cockpit
* Работа в паре с OnSiteSeq Edge или автономно
* Постоянно обновляющийся маркетплейс x86-контейнеров
* Поддержка данных с любого оборудования в формате FASTQ

---

## 📦 Пайплайны

Биоинформатические инструменты распространяются через [OnSiteSeq Harbor](https://harbor.onsiteseq.io) в виде x86 Docker-контейнеров.
