## 📋 Описание

OnSiteSeq Cockpit — веб-приложение для управления контейнеризованными биоинформатическими Snakemake-пайплайнами. Позволяет запускать анализ из браузера: выбрать пайплайн из каталога Harbor, указать входной образец `.fastq.gz` и получить клинический и QC-отчёты без работы в командной строке.

---

## 🖥 Варианты исполнения

### Edge

Версия для запуска на программно-аппаратном комплексе OnSiteSeq Edge. Интерфейс адаптирован для работы на сенсорном экране. Пайплайны распространяются в виде **arm64** Docker-контейнеров через реестр `harbor.onsiteseq.io`.

| Параметр | Значение |
| :--- | :--- |
| **Архитектура** | arm64 |
| **Целевое устройство** | Nvidia Jetson AGX |
| **Контейнеры** | arm64 Docker-образы |

### Desktop

Версия для запуска на рабочем компьютере врача или исследователя. Работает автономно или в паре с OnSiteSeq Edge. Пайплайны распространяются в виде **x86** Docker-контейнеров.

| Параметр | Значение |
| :--- | :--- |
| **Архитектура** | x86 |
| **Целевое устройство** | Рабочий компьютер |
| **Контейнеры** | x86 Docker-образы |

### Cloud

Версия, адаптированная для запуска в облачных провайдерах. Доступна по адресу [cloud.onsiteseq.io](https://cloud.onsiteseq.io). Пайплайны распространяются в виде **x86** Docker-контейнеров.

| Параметр | Значение |
| :--- | :--- |
| **Архитектура** | x86 |
| **Адрес** | cloud.onsiteseq.io |
| **Контейнеры** | x86 Docker-образы |

## ⚙️ Технологический стек

| Слой | Технология |
| :--- | :--- |
| **Frontend** | Vue 3 + Vite + Pinia + Axios |
| **Backend** | Python 3.12 + FastAPI + SQLAlchemy async |
| **БД** | PostgreSQL 16 (asyncpg драйвер) |
| **Миграции** | Alembic (async) |
| **Реестр образов** | Harbor Registry (harbor.onsiteseq.io) |
| **Оркестрация** | Docker Compose v2 |
| **Веб-сервер фронтенда** | Nginx (статика из Vite build) |

### Каталог пайплайнов

Карточки доступных пайплайнов с тегами, статусом совместимости (Edge / Cockpit / Cloud) и кнопкой запуска. Синхронизация каталога с `harbor.onsiteseq.io` в один клик.

### Запуск анализа

Выбор пайплайна, названия запуска и входного образца `.fastq.gz`. Файлы обнаруживаются автоматически из папки данных.

### Результаты: клинический и QC-отчёты

После завершения анализа Cockpit отображает прогресс выполнения шагов Snakemake и список готовых отчётов: клинический (для врача) и QC-отчёт (для биоинформатика).
