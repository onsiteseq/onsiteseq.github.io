## 🧠 Подход

Стандартные зарубежные алгоритмы часто обучаются на базах данных, не отражающих специфику Российской Федерации: в России доминирует субтип **A6**, редкий на Западе, а эпидемия носит выраженный монофилетический характер.

Наши нейросетевые модели ориентированы на субтипы, циркулирующие в РФ, и проверяются на независимой российской когорте **EpidRuSeq** (ФБУН ЦНИИ Эпидемиологии Роспотребнадзора). Код и веса моделей открыты на [GitVerse](https://gitverse.ru/onsiteseq). Статус — исследовательский (RUO).

> **Субтип зависит от участка генома.** У рекомбинантных форм (в т.ч. CRF63_02A6) субтип по *env* и по *pol* может законно различаться. В отчётах всегда указано, по какому гену определён субтип.

## 🧬 HIV-1-M-Env-Rus — субтип по гену env {#env}

Классификатор субтипов ВИЧ-1 по нуклеотидной последовательности гена *env* для нанопоровых данных (пайплайн **OnSiteSeq HIV**). Репозиторий: [gitverse.ru/onsiteseq/HIV-1-M-Env-Rus](https://gitverse.ru/onsiteseq/HIV-1-M-Env-Rus)

* **12 классов:** CRF02_AG, A2, D, F2, G, H, A6, CRF63_02A6, A1, B, C, F1 — включая формы, значимые для РФ.
* **Архитектура:** свёрточный автоэнкодер (CAE) на частотах k-меров (k = 6, вектор 4096): энкодер из 3 слоёв Conv1d и 2 резидуальных блоков, декодер для функции потерь реконструкции (MSE), классификатор из 3 полносвязных слоёв.
* **Синтетическая эволюция *in silico*:** рекомбинации, вставки и делеции для расширения редких классов; качество генерации контролируется t-SNE на тех же 6-мерах, что подаются в модель.
* **Контроль входа (с 11.10.2026):** длина, доля не-ACGT, сходство с панелью эталонных *env* по 12-мерам, автоопределение цепи, порог уверенности. Статусы: `OK`, `LOW_CONFIDENCE`, `SHORT`, `AMBIGUOUS`, `NOT_HIV1M_ENV`. Раньше модель уверенно «классифицировала» polyA, обратную цепь и V3-петлю — теперь такие входы отбраковываются.

**Исправления 11.10.2026:**
* разбиение train / val / test по кластерам близких последовательностей (косинус 6-меров ≥ 0.90): в LANL у субтипа B до 784 клонов на пациента, и случайное разбиение раскладывало их по обеим выборкам;
* итоговые метрики считаются на test, а не на val, которая расходуется на выбор лучшей эпохи;
* синтетические рекомбинанты проверяются на валидность рамки считывания (100% валидны вместо 39–73% у части классов);
* единый seed — прогоны воспроизводимы.

**Метрики:** прежние метрики модели получены с утечкой между выборками и сняты с публикации. Пересчёт на чистом тестовом разбиении — в работе.

**Ограничения:** уникальные рекомбинантные формы (URF) и CRF вне 12 классов модель сводит к ближайшему классу, и контроль входа их не ловит; нужен полноразмерный *env*; метрики малых классов (H, A2, CRF63_02A6) статистически не значимы.

## 🧪 HIV-1-M-Pol-Rus — субтип по гену pol {#pol}

Классификатор субтипов ВИЧ-1 по участку *pol* PR+RT — стандартному ампликону капиллярного (Sanger) секвенирования. Модель Env к такому входу неприменима, поэтому для пайплайна **OnSiteSeq HIV Sanger** создана отдельная модель. Репозиторий: [gitverse.ru/onsiteseq/HIV-1-M-Pol-Rus](https://gitverse.ru/onsiteseq/HIV-1-M-Pol-Rus)

* **7 классов:** A6, A1, B, G, CRF02_AG, CRF63_02A6 и **OTHER** («не из шести целевых»: URF и составные формы, признанные CRF, чистые не-РФ субтипы). OTHER — ответ модели, а не отказ контроля входа (`Unclassified`).
* **Архитектура:** CAE на частотах k-меров (k = 6, вектор 4096) — результат не зависит от длины фрагмента.
* **Разбиение по ID пациента:** train / val / test назначаются по пациентам один раз; доля записей val/test от пациентов из train — **0%** (регрессионный тест `check_leakage.py`).
* **Контроль входа:** статусы `OK`, `LOW_CONFIDENCE`, `SHORT`, `AMBIGUOUS`, `NOT_HIV1M_POL`, `EMPTY`; обратная цепь определяется автоматически.

### Метрики (полный прогон 17.10.2026)

| Набор | n | Accuracy | Комментарий |
| :--- | :---: | :---: | :--- |
| Внутренний holdout (LANL) | 441 | 0.887 | F1-macro 0.789; без класса OTHER (6 классов) — 0.997 |
| **EpidRuSeq, разметка COMET (основная метрика)** | 251 | **0.992** | recall A6 1.000 (196/196), B 0.974, CRF63_02A6 0.923 |
| EpidRuSeq, разметка fallback | 90 | 0.667 | метки моделью того же семейства — не независимый эталон |
| EpidRuSeq, весь тест | 343 | 0.906 | 341 классифицировано + 2 `Unclassified` по контролю входа |

Тестовая когорта очищена от записей, почти совпадающих с обучающими (исключено 8 записей с косинусом 6-меров ≥ 0.999).

**Ограничения:** по субтипу G независимо размечены лишь 2 записи — заявки о валидации нет. OTHER — не детектор рекомбинантов: на A6-содержащих мозаиках recall 0.357 (15/42; 95% ДИ 0.216–0.520). Цена класса OTHER для целевых классов мала: recall A6 на COMET остался 1.000.

## 🛡️ HIV-1-Resist-Rus — лекарственная устойчивость {#resist}

Предсказание резистентности к **14 препаратам** четырёх классов АРТ (НИОТ, ННИОТ, ИП, ИНСТИ) по белкам PR, RT и IN. Используется в обоих пайплайнах — ONT и Sanger. Репозиторий: [gitverse.ru/onsiteseq/HIV-1-Resist-Rus](https://gitverse.ru/onsiteseq/HIV-1-Resist-Rus)

### История версий

| Версия | Дата | Что изменилось |
| :--- | :--- | :--- |
| 1.0 | 02.2026 | Один препарат (DTG), сравнение CNN и CNN + Self-Attention, разметка по fold-change |
| 3.0 | 06.2026 | 14 препаратов, обучающий корпус LANL (37 641 последовательность) с разметкой Stanford Sierra, внешняя валидация на 356 пациентах |
| 3.1 | 12.10.2026 | Дедупликация по генотипу (устранена утечка одинаковых последовательностей между train и val), полный словарь мутационных флагов, калибровка Платта, контроль качества входа |
| 3.2 | 12.10.2026 | Сквозной воспроизводимый `dvc repro`, регрессионный baseline, модели третьего поколения |
| **4.0** | **13.10.2026** | **Пятиуровневый выход HIVDB (CORAL), список мутаций в отчёте, гейт надёжности уровней** |

### Архитектура HybridResistanceCNN (v4.0)

* **Embedding → Conv1D ×2 + MaxPool → Self-Attention** — локальные паттерны и дальние взаимодействия в аминокислотной последовательности (RT: 240 позиций / PR: 99 / IN: 288).
* **MutationMLP** — флаги ключевых мутаций по словарю Stanford HIVDB (НИОТ 15 / ННИОТ 16 / ИП 19 / ИНСТИ 15 позиций).
* **Fusion → CORAL-голова** — кумулятивные вероятности P(уровень ≥ 2…5) по пятиуровневой шкале HIVDB, монотонные по построению; P(уровень ≥ 2) — прежний бинарный выход.
* **Обучение:** Focal Loss (α = 0.75, γ = 2.0) против дисбаланса классов, дедупликация по генотипу, порог по индексу Юдена и калибровка Платта на каждую границу. Уровни, для которых меньше 30 обучающих примеров, помечаются в отчёте «*».
* **Контроль входа:** идентичность к HXB2 ≥ 80%, доля неоднозначных остатков, длина, стоп-кодоны; статусы `OK`, `LOW_IDENTITY`, `FRAMESHIFT`, `SHORT`, `NOT_FOUND`. Не прошедший контроль ген в модель не передаётся — в отчёте явное «не определено».
* **Отчёт:** уровень резистентности по каждому препарату и список мутаций; полиморфизмы субтипа A6 (включая L74I) выводятся отдельно и в мутации резистентности не входят.

## ⚙️ Технологии и BioMLOps

Мы применяем практики управления жизненным циклом моделей машинного обучения в биомедицине (**BioMLOps**) — для воспроизводимости результатов.

* **Управление данными (DVC):** версионирование обучающих датасетов, весов моделей и пайплайнов подготовки данных (HIV-1-Resist-Rus).
* **Регрессионный контроль:** при переобучении метрики внутренней и внешней валидации сравниваются с зафиксированным baseline; падение сильнее порога останавливает выкатку (CI на GitVerse).
* **Воспроизводимость:** пайплайны Snakemake (HIV-1-M-Env-Rus, HIV-1-M-Pol-Rus), единый seed для всех случайных операций.
* **Технологический стек:** `PyTorch (>=2.0)`, `Snakemake`, `DVC`, `BioPython`.
