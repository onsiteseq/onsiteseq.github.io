## 🧠 Архитектура SynergyTBGraph

В основе нашего биоинформатического комплекса для анализа туберкулеза лежит проприетарная гибридная архитектура **SynergyTBGraph**. Она разработана специально для преодоления проблем нанопорового секвенирования (шумы) и сложной биологии возбудителя (эпистаз).

Архитектура представляет собой слияние трех модулей глубокого обучения:
1. **LLMTB (Macro-tokenizer):** Разделение генов на кодирующие (CDS) и промоторные зоны.
2. **RGTFormer (Relational Graph Transformer):** Сборка реляционных графов мутаций, учитывающих типы связей и метаболические пути в клетке.
3. **VAMP-Net:** Модуль на базе 1D-CNN для подавления шума секвенирования и механизма Set Attention для моделирования глобального контекста и поиска эпистатических взаимодействий.

## 🔬 TB-Res-Detector (Версия 2.0) {#tb-res-detector}

Флагманская модель для предсказания минимальной подавляющей концентрации (MIC) и множественной лекарственной устойчивости (МЛУ/ШЛУ). 

* **Механизм работы:** Принимает на вход сгенерированные макро-токены и графы признаков. Рассчитывает индекс эпидемиологической опасности (OnSiteSeq Index v2.0).
* **Спектр действия:** Автоматическая валидация по 13 противотуберкулезным препаратам.
* **Калибровка:** Пороги принятия решений математически откалиброваны с использованием индекса Юдена для максимизации чувствительности и специфичности.

### Поддерживаемые препараты и клинические SGI-пороги
Модель оперирует настраиваемыми клиническими порогами для каждого антибиотика:

| Класс препаратов | Препараты | SGI Порог (Threshold) |
| :--- | :--- | :--- |
| **Препараты 1-го ряда** | Рифампицин (RIF)<br>Изониазид (INH)<br>Этамбутол (EMB)<br>Пиразинамид (PZA) | `0.655`<br>`0.528`<br>`4.519`<br>`100.0` |

| **Препараты Группы B / C** | Бедаквилин (BDQ)<br>Линезолид (LZD)<br>Клофазимин (CFZ)<br>Деламанид (DLM) | `1.075`<br>`3.027`<br>`0.687`<br>`0.615` |

| **Прочие** | Этионамид (ETH) | `3.440` |

## 🧬 TB-Lineage-Detector (Версия 2.0) {#tb-lineage-detector}

Модуль для точной классификации доминирующих генетических линий *Mycobacterium tuberculosis* (например, линий Beijing), в том числе специфичных для Российской Федерации.

* **Тренировочная база:** Обучение проводилось с использованием масштабной международной базы данных геномов (The CRyPTIC Consortium, 12 289 изолятов).
* **Пайплайн:** Парсинг исходных Parquet-файлов, векторизация и извлечение мутационных паттернов для формирования PyTorch-тензоров.

## ⚙️ Hyperparameters & BioMLOps

Мы придерживаемся строгих стандартов MLOps в биомедицине (BioMLOps), используя DVC для версионирования датасетов и графов `data/processed/graphs`.

**Ключевые гиперпараметры обучения моделей:**
* **Размерность:** `embed_dim: 64`, `max_seq_length: 50`
* **Сверточные фильтры (1D-CNN):** `cnn_out_dim: 128` (поиск локальных мотивов резистентности)
* **Механизм внимания (Self-Attention):** `num_heads: 4`
* **Регуляризация:** `dropout: 0.3`, Early Stopping (`patience: 10`)
* **Оптимизация:** Обучение (50 эпох, Batch Size 32, `learning_rate: 0.0005`) с использованием функций потерь `BCELoss` и `Huber Loss`.
