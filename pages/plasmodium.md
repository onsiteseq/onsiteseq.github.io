## 🧬 Описание пайплайна

*Plasmodium falciparum* — возбудитель наиболее тяжёлой формы малярии. Главная угроза последних лет — распространение частичной устойчивости к **артемизинину** (терапия первой линии) из Юго-Восточной Азии в Африку. Для России малярия — завозная инфекция: задача пайплайна у нас — **верификация завозных случаев**, видовая идентификация и оценка резистентности привезённого штамма за часы вместо референс-лабораторий.

Пайплайн анализирует валидированные ВОЗ маркеры резистентности (*kelch13*, *pfcrt*, *pfmdr1*, *dhfr*, *dhps*, амплификация *plasmepsin2/3*) и делеции диагностических генов *hrp2/hrp3*. Для высоковариабельных локусов применяется **локусное графовое выравнивание (OnSiteSeq-PanG)**, снижающее систематическое смещение референса (reference bias); консервативные маркеры анализируются стандартным выравниванием.

* **📥 На входе:** Сырые данные в формате `FASTQ` после High Accuracy basecalling (Dorado SUP, R10.4.1). Материал: цельная кровь (с обогащением паразитарной ДНК или ампликонным обогащением целевых локусов).
* **📤 На выходе:** HTML-отчёт с видом плазмодия, профилем чувствительности, статусом *hrp2/hrp3* и выявленными мутациями.

## 🎯 Гены и мутации резистентности

| Ген | Ключевые мутации | Класс препаратов / Значение |
| :--- | :--- | :--- |
| **kelch13** (K13) | C580Y, R539T, Y493H, M476I (Азия); **R561H** (валидирован в Африке — Руанда, Уганда) | **Артемизинин** — задержка клиренса паразита |
| **pfcrt** | K76T | **Хлорохин** |
| **pfmdr1** | N86Y, Y184F, D1246Y; амплификация копийности | **Мефлохин, Люмефантрин** (модуляция чувствительности) |
| **dhfr** | N51I, C59R, S108N | **Пириметамин** |
| **dhps** | A437G, K540E | **Сульфадоксин** |
| **plasmepsin2/3** | Амплификация копийности | **Пиперахин** — партнёрский препарат ACT |

### Делеции hrp2/hrp3 — угроза экспресс-диагностике

Делеции генов *hrp2* и *hrp3* делают паразита «невидимым» для экспресс-тестов (RDT) на антиген HRP2 — ложноотрицательный результат при реальной инфекции. Длинные нанопоровые риды детектируют эти делеции напрямую, без сборки генома. Отчёт включает статус *hrp2/hrp3* с интерпретацией для врача: при делеции RDT-отрицательный результат не исключает малярию — показана ПЦР/микроскопия.

### Видовая идентификация

Помимо *P. falciparum*, пайплайн различает *P. vivax*, *P. ovale*, *P. malariae* и зоонозный *P. knowlesi* по локусу 18S рРНК — вид определяет тактику (при *P. vivax/ovale* обязательна противорецидивная терапия примахином с учётом статуса G6PD).

## 🛠 Под капотом: Зависимости и Окружение (Pipeline Stack)

Пайплайн управляется фреймворком Snakemake в изолированных Conda-окружениях.

| Этап пайплайна | Ключевые библиотеки и инструменты |
| :--- | :--- |
| **1. Контроль качества (QC)** | `porechop_abi`, `NanoFilt`, `pigz` |
| **2. Выравнивание (Mapping)** | `minimap2` (референс: 3D7); **OnSiteSeq-PanG** для высоковариабельных локусов |
| **3. Поиск мутаций (Variant Calling)** | `clair3`, `medaka` |
| **4. Аннотация резистентности** | Кастомная база валидированных маркеров ВОЗ (k13/pfcrt/pfmdr1/dhfr/dhps) |
| **5. Детекция делеций** | Анализ покрытия локусов *hrp2/hrp3* по длинным ридам |
| **6. Видовая идентификация** | `minimap2` + классификация по панели 18S рРНК |
| **7. ML-инференс** | `PyTorch`, `pandas`, `scikit-learn` |

## 🌍 Глобальный контекст: почему это важно

* **ВОЗ, World Malaria Report** — ~250 млн случаев и ~600 тыс. смертей от малярии ежегодно; геномный надзор за резистентностью назван приоритетом.
* **Африка** — частичная резистентность к артемизинину (маркер R561H) подтверждена в Руанде и Уганде: риск повторения сценария утраты хлорохина.
* **Россия** — малярия элиминирована, но ежегодно регистрируются завозные случаи; быстрая верификация вида и резистентности критична для тактики лечения и противоэпидемических мер.
* **Делеции hrp2/hrp3** — распространение RDT-негативных штаммов подрывает доверие к экспресс-тестам в эндемичных регионах.
