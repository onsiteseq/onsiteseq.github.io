## 📄 Два уровня отчётности

Архитектура пайплайна **OnSiteSeq HIV** автоматически генерирует два типа отчётов, разделяя клиническую интерпретацию для врача-инфекциониста и строгие метрики качества для биоинформатика.

### 1. Клинический отчёт для врача (Clinical Report)
Этот документ переводит сложные генетические данные на язык клинических решений, позволяя врачу быстро подобрать эффективную схему АРВТ (антиретровирусной терапии).

**Ключевые особенности:**
* Определение субтипа вируса (например, доминирующего в РФ субтипа A6).
* Оценка чувствительности к основным классам препаратов:
  * **НИОТ** (например, *Тенофовир (TDF)*)
  * **ННИОТ** (например, *Эфавиренз (EFV)*, *Этравирин (ETR)*)
  * **ИП** (например, *Дарунавир (DRV)*)
  * **ИИ** (например, *Биктегравир (BIC)*)
* Расчёт процентной вероятности восприимчивости вируса к каждому конкретному препарату на базе ML-модели `HIV-1-Resist-Rus`.

🔗 **[Посмотреть пример клинического HTML-отчёта](/assets/pdf/reports/hiv/final_report.html)**

### 2. Отчёт контроля качества (QC Report)
Специализированный документ для оценки достоверности биоинформатической сборки и валидации результатов секвенирования.

**Ключевые особенности:**
* Метрики выравнивания на эталонный геном ВИЧ-1 (HXB2 / `Ref.B.FR.83.HXB2_LAI_IIIB_BRU.K03455`).
* Фиксация целевых участков: автоматическая проверка успешной сборки ключевых генов резистентности — **PR** (протеаза), **RT** (обратная транскриптаза) и **IN** (интеграза).
* Отслеживание метрик покрытия (Coverage, например: `94.37%`) и сверхвысокой глубины прочтения (Depth, например: `4298.4x`).
* Контроль «слепых зон» (N) в итоговой консенсусной последовательности.

## 🛡️ Соответствие стандартам ALCOA+ (Data Integrity)

Все процессы внутри программно-аппаратного комплекса OnSiteSeq спроектированы в строгом соответствии с международной методологией **ALCOA+**, применяемой в медицинской диагностике и фармацевтике для защиты целостности данных.

| Принцип ALCOA+ | Реализация в OnSiteSeq Edge |
| :--- | :--- |
| **A – Attributable** *(Атрибутируемость)* | Система требует авторизации медработника перед запуском. В каждом отчете жестко фиксируются версии используемых алгоритмов (например, `onsiteseq_hiv v1.0.0`, `HIV-1-M-Env-Rus v1.0.0`). |
| **L – Legible** *(Читаемость)* | Данные преобразуются в наглядные HTML-отчёты с цветовой индикацией восприимчивости к препаратам (зеленый/красный) для исключения ошибок интерпретации. |
| **C – Contemporaneous** *(Своевременность)* | Отчёты получают защищенную метку времени (Timestamp). Внутренние часы устройства синхронизируются через встроенный модуль Wi-Fi/4G и не поддаются ручному изменению. |
| **O – Original** *(Оригинальность)* | До работы base-caller модели Dorado, первичные электрические сигналы с нанопоры сохраняются в неизменных форматах (POD5/FAST5) на SSD-диск. |
| **A – Accurate** *(Точность)* | Высочайшая точность подтверждается выводом в QC-отчёт детальных параметров (например, глубина `4298x`). Вывод уровня уверенности нейросети защищает от ложноположительных результатов. |
| **+ (Plus)** *(Полнота и Доступность)* | Интеграция с фреймворком Snakemake гарантирует сохранение всех логов, включая данные о прерванных запусках или отбракованных чтениях низкого качества. |
