## 🧬 Описание пейплайна

*Helicobacter pylori* — грамотрицательная бактерия, колонизирующая слизистую желудка и являющаяся главной причиной хронического гастрита, язвенной болезни и фактором риска рака желудка (канцероген I группы по классификации IARC). Успех эрадикационной терапии напрямую зависит от чувствительности штамма к антибиотикам — в первую очередь к кларитромицину и левофлоксацину.

Наш пайплайн по данным нанопорового секвенирования определяет полный профиль устойчивости и ключевые факторы вирулентности (*cagA*, *vacA*) непосредственно из биоптата, без культивирования — *H. pylori* капризен и медленно растёт, поэтому классическая бактериология занимает 7–14 дней.

* **📥 На входе:** Сырые данные в формате `FASTQ` после High Accuracy basecalling (химия R10.4.1, модель Dorado SUP). Материал: биоптат антрального отдела или тела желудка. Оптимально: ампликонное секвенирование локусов *23S рРНК* и *gyrA* **или** полногеномное секвенирование (WGS) культуры/обогащённого образца.
* **📤 На выходе:** HTML-отчёт для клинициста с профилем чувствительности к антибиотикам эрадикационных схем и статусом факторов вирулентности; QC-отчёт для биоинформатика.

## 🎯 Гены и мутации резистентности

| Ген / Локус | Ключевые мутации | Класс антибиотиков |
| :--- | :--- | :--- |
| **23S рРНК** | A2142G, A2143G, A2142C | **Кларитромицин** (макролиды) — ключевой препарат первой линии |
| **gyrA** | N87K, D91G/N/Y | **Левофлоксацин** (фторхинолоны) — терапия спасения |
| **pbp1A** | Множественные аминокислотные замены | **Амоксициллин** (резистентность редка, но растёт) |
| **rdxA, frxA** | Делеции, нонсенс-мутации (инактивация) | **Метронидазол** |
| **16S рРНК** | A926G, A928C | **Тетрациклин** |
| **rpoB** | Точечные мутации (кластер rif-региона) | **Рифабутин** — терапия третьей линии |
| **porD, oorD** | Инактивирующие мутации | **Фуразолидон** |

### Профиль антибиотиков в отчёте

| Антибиотик | Место в схемах (Маастрихт VI) | Клиническое значение |
| :--- | :--- | :--- |
| **Кларитромицин** | Тройная терапия первой линии | При региональной резистентности >15% эмпирическое назначение не рекомендуется — нужен генотип |
| **Амоксициллин** | Компонент всех схем | Резистентность редка; опора эрадикации |
| **Метронидазол** | Компонент тройной/квадротерапии | Высокая фоновая резистентность; частично преодолевается дозой и длительностью |
| **Левофлоксацин** | Терапия второй линии (спасения) | Резистентность быстро растёт при необоснованном применении ФХ |
| **Тетрациклин** | Квадротерапия с висмутом | Резистентность пока редка |
| **Рифабутин** | Терапия третьей линии | Резерв при множественных неудачах эрадикации |

## 🧫 Факторы вирулентности

Помимо устойчивости, отчёт включает статус ключевых факторов вирулентности — это прогностически значимая информация для врача:

| Фактор | Варианты | Клиническое значение |
| :--- | :--- | :--- |
| **cagA** (островок cagPAI) | Наличие / отсутствие | cagA+ штаммы — повышенный риск язвенной болезни и рака желудка |
| **vacA** | Аллели s1/s2, m1/m2 | s1/m1 — наиболее токсигенный вариант, ассоциирован с тяжёлым течением |

Именно здесь оправдано **локусное графовое выравнивание (OnSiteSeq-PanG)**: cagPAI и *vacA* — высоковариабельные регионы с частыми рекомбинациями и делециями, где единый линейный референс даёт сбои. Граф кодирует все известные аллельные варианты локуса и повышает полноту картирования ридов в этих регионах. Для консервативных генов устойчивости (23S рРНК, *gyrA*) применяется стандартное выравнивание — там оно надёжно.

## 🛠 Под капотом: Зависимости и Окружение (Pipeline Stack)

Пайплайн управляется фреймворком Snakemake в изолированных Conda-окружениях.

| Этап пайплайна | Ключевые библиотеки и инструменты |
| :--- | :--- |
| **1. Контроль качества (QC)** | `porechop_abi`, `NanoFilt`, `pigz` |
| **2. Выравнивание (Mapping)** | `minimap2` (референс: 26695 / J99); локусные пангеномные графы **OnSiteSeq-PanG** для cagPAI/vacA |
| **3. Поиск мутаций (Variant Calling)** | `clair3`, `medaka` |
| **4. Аннотация резистентности** | Кастомная база мутаций 23S/gyrA/pbp1A/rdxA/frxA/16S/rpoB + `AMRFinderPlus` |
| **5. Типирование вирулентности** | Детекция cagPAI, аллельное типирование *vacA* (s/m-регионы) |
| **6. ML-инференс** | `PyTorch`, `pandas`, `scikit-learn` |

## 🌍 Глобальный контекст: почему это важно

* **ВОЗ, 2017** — кларитромицин-резистентный *H. pylori* включён в список приоритетных патогенов по АМР (высокий приоритет).
* **Россия** — резистентность к кларитромицину оценивается в 20–30%, что превышает порог Маастрихт VI (15%): эмпирическая тройная терапия без генотипирования всё чаще заканчивается неудачей.
* **Рак желудка** — *H. pylori* признан канцерогеном I группы (IARC); статус cagA/vacA уточняет индивидуальный риск.
* Текущий стандарт — культуральный метод с антибиотикограммой: 7–14 дней и низкая изоляционная успешность. Наш пайплайн даёт **результат в тот же день** непосредственно из биоптата.
