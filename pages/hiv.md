## 🧬 Описание пайплайна

Наш алгоритм обеспечивает полный цикл обработки данных секвенирования для выявления мутаций лекарственной устойчивости и точного определения субтипа ВИЧ-1.

* **📥 На входе** — два пайплайна под две платформы секвенирования:
  * **ONT (нанопоровое секвенирование)** — сырые данные `FASTQ` после базколлинга Dorado (POD5/FAST5 → FASTQ). Пайплайн **OnSiteSeq HIV**, субтип по гену *env*.
  * **Sanger (капиллярное секвенирование)** — хроматограммы `.ab1` (прямое и обратное прочтения ампликона *pol* PR-RT) или готовый консенсус `FASTA`. Пайплайн **OnSiteSeq HIV Sanger**, субтип по гену *pol*.
* **📤 На выходе:** Исследовательский HTML-отчёт (RUO) и расширенный отчёт для биоинформатика.

## 🧭 Класс по Балтимору: VI — (+)ssRNA-RT (ретровирусы)

Класс VI объединяет ретровирусы: их геном — одноцепочечная РНК положительной полярности, однако она не работает напрямую как мРНК — сначала вирусная **обратная транскриптаза** (ОТ, ген *pol*) переписывает РНК в ДНК, а **интеграза** встраивает эту ДНК-копию в геном хозяина, образуя **провирус**. ВИЧ-1 — канонический представитель класса: провирус становится постоянной частью клетки и пожизненным источником новых вирусных частиц, именно поэтому инфекцию невозможно элиминировать современной терапией. Обратная транскриптаза лишена корректирующей (3'→5'-экзонуклеазной) активности, поэтому ошибки при копировании накапливаются на порядки быстрее, чем у клеточных ДНК-полимераз — отсюда квазивидовое разнообразие ВИЧ у каждого пациента и стремительный отбор устойчивых вариантов под давлением препаратов. Именно поэтому лекарственная устойчивость ВИЧ — это мутации в гене *pol* (обратная транскриптаза, протеаза, интеграза), которые и читает наш пайплайн по правилам Stanford HIVdb.

| Класс | Геном | Стратегия репликации | Примеры |
| :--- | :--- | :--- | :--- |
| I | dsDNA | ДНК → мРНК (как у клетки) | Герпесвирусы, аденовирусы, оспа, АЧС |
| II | ssDNA (+) | Через промежуточную dsDNA | Парвовирусы |
| III | dsRNA | РдРП транскрибирует с dsRNA | Ротавирусы |
| IV | (+)ssRNA | Геном = мРНК, сразу трансляция | SARS-CoV-2, гепатит C |
| V | (−)ssRNA | Сначала синтез (+)цепи (РдРП) | Грипп, SFTS, бешенство |
| **VI** | **(+)ssRNA-RT** | **Обратная транскриптаза: РНК → ДНК** | **ВИЧ, ретровирусы** |
| VII | dsDNA-RT | Реверт-транскрипция через РНК-интермедиат | Гепатит B |

## 🎯 Гены и мутации резистентности

ONT-пайплайн анализирует ген *pol* целиком — все три фермента-мишени антиретровирусной терапии; Sanger-пайплайн — в пределах секвенированных ампликонов (обычно PR+RT; IN — при наличии отдельного ампликона). Интерпретация мутаций выполняется по правилам **Stanford HIVdb** — мирового стандарта генотипической интерпретации ЛУ-ВИЧ.

| Класс препаратов | Ген | Ключевые мутации | Препараты |
| :--- | :--- | :--- | :--- |
| **НИОТ** (нуклеозидные ингибиторы ОТ) | RT | M184V/I, K65R, тимидиновые (M41L, D67N, T215Y/F, K219Q/E) | Тенофовир, Ламивудин, Абакавир |
| **ННИОТ** (ненуклеозидные ингибиторы ОТ) | RT | K103N, Y181C, G190A, E138K | Эфавиренз, Невирапин, Рилпивирин, Доравирин |
| **ИП** (ингибиторы протеазы) | PR | D30N, M46I/L, I50V, I54V/M, V82A/F/T, L90M | Атазанавир, Дарунавир, Лопинавир |
| **ИНСТИ** (ингибиторы интегразы) | IN | Q148H/R/K, G118R, R263K, N155H | Долутегравир, Биктегравир, Ралтегравир |

Ингибиторы интегразы — первая линия современной АРТ (долутегравир включён в российские клинические рекомендации), поэтому мониторинг мутаций интегразы (Q148 + вторичные) имеет особое значение.

## 🛠 Под капотом: Зависимости и Окружение (Pipeline Stack)

Пайплайны управляются с помощью фреймворка Snakemake и разделены на изолированные Conda-окружения для максимальной воспроизводимости.

### OnSiteSeq HIV (ONT)

| Этап пайплайна | Используемые библиотеки и инструменты |
| :--- | :--- |
| **1. Контроль качества (QC)** | `Python 3.10`, `porechop_abi`, `NanoFilt`, `pigz` |
| **2. Выравнивание (Alignment)** | `minimap2`, `samtools` |
| **3. Сборка консенсуса** | `medaka 1.11.*`, `bcftools`, `htslib` |
| **4. ML Предсказание** | `PyTorch >=2.0`, `BioPython`, `pandas`, `scikit-learn` |

### OnSiteSeq HIV Sanger

| Этап пайплайна | Используемые библиотеки и инструменты |
| :--- | :--- |
| **1. QC хроматограмм** | `tracy` (резерв — `BioPython SeqIO "abi"`), тримминг концов по phred |
| **2. Сборка прочтений и консенсус** | overlap-сборка прямого и обратного прочтений, консенсус с IUPAC-кодами (второй пик ≥ 25%) |
| **3. Выравнивание и варианты** | `minimap2` на HXB2 (K03455.1), замены по координатам HXB2 |
| **4. ML Предсказание** | `PyTorch`, HIV-1-M-Pol-Rus (субтип), HIV-1-Resist-Rus (резистентность) |

## 🌍 Глобальный контекст: почему это важно

* **Россия** — более 1 млн людей живут с ВИЧ; в стране и Восточной Европе доминирует **субтип A6** (бывш. A-FSU), редкий на Западе. Наши модели `HIV-1-M-Env-Rus`, `HIV-1-M-Pol-Rus` и `HIV-1-Resist-Rus` ориентированы на субтипы, циркулирующие в РФ, и проверяются на российской когорте EpidRuSeq — это их ключевое отличие от западных аналогов, заточенных под субтип B.
* **ВОЗ** — генотипическое тестирование лекарственной устойчивости рекомендовано до старта АРТ: переданная устойчивость к ННИОТ в ряде регионов превышает 10%-й порог.
* **INSTI-эра** — переход первой линии на долутегравир делает мониторинг мутаций интегразы приоритетом надзора за ЛУ-ВИЧ.
