OnSiteSeq Cloud

Система управления биоинформатическими пайплайнами в облаке

📋 Описание

OnSiteSeq Cloud — вариант системы управления биоинформатическими пайплайнами OnSiteSeq Cockpit, адаптированный для запуска в облачных провайдерах. Доступен по адресу cloud.onsiteseq.io. Может работать в паре с OnSiteSeq Edge или использовать данные, полученные на другом оборудовании.

🔧 Ключевые характеристики

Параметр Значение
Архитектура x86
Адрес cloud.onsiteseq.io
Реестр контейнеров harbor.onsiteseq.io (x86 Docker-образы)

⚙️ Возможности

  • Запуск анализа через браузер без установки ПО
  • Масштабируемость под облачные провайдеры
  • Постоянно обновляющийся маркетплейс x86-контейнеров
  • Поддержка данных с любого оборудования в формате FASTQ

🔗 Перейти в облако

→ cloud.onsiteseq.io

📦 Пейплайны

Биоинформатические инструменты распространяются через OnSiteSeq Harbor в виде x86 Docker-контейнеров.

  • OnSiteSeq TUB — Туберкулёз
  • OnSiteSeq HIV — ВИЧ-1
